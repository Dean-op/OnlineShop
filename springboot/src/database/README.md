## 🚀 导入步骤

### 方法一：使用 MySQL 命令行（推荐）

```bash
# 1. 进入 MySQL
mysql -u root -p

# 2. 在 MySQL 中执行
source E:/IdeaProjects/web_project/个性化推荐商城/springboot/src/database/full_database.sql;

# 或者直接在命令行执行
mysql -u root -p < "E:/IdeaProjects/web_project/个性化推荐商城/springboot/src/database/full_database.sql"
```

### 方法二：使用 Navicat 或其他数据库工具

1. 打开 Navicat
2. 连接到 MySQL 数据库
3. 点击 "文件" → "运行 SQL 文件"
4. 选择 `full_database.sql`
5. 点击 "开始" 执行

### 方法三：使用 PowerShell（Windows）

```powershell
# 切换到数据库脚本目录
cd "E:\IdeaProjects\web_project\个性化推荐商城\springboot\src\database"

# 执行导入
Get-Content full_database.sql | mysql -u root -p
```

## ❓ 常见问题

### Q1: 导入时提示"Table doesn't exist"

**A**: 确保按顺序执行整个SQL文件，不要分段执行。

### Q2: 导入后登录提示密码错误

**A**: 所有用户的密码都是 `123456`（已使用 BCrypt 加密）

### Q3: 图片无法显示

**A**: 确保 `springboot/files/img/` 目录下有对应的图片文件。

### Q4: 菜单显示404

**A**: 本脚本已经修复了菜单路径问题，`page_path` 已与实际Vue组件文件名匹配。
