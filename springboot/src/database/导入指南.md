# 数据库初始化完整指南

## 🔧 问题解决：导入数据报错

### 错误信息：
```
ERROR 1146 (42S02): Table 'product_system.user_behavior' doesn't exist
```

### 解决方案：

**方法1：按正确顺序执行（推荐）**

```bash
# 第一步：创建数据库和所有表
mysql -u root -p < springboot/src/database/create_tables.sql

# 第二步：插入示例数据
mysql -u root -p < springboot/src/database/insert_sample_data.sql
```

**方法2：使用MySQL客户端**

```bash
# 1. 登录MySQL
mysql -u root -p

# 2. 在MySQL中执行
mysql> source E:/IdeaProjects/web_project/个性化推荐商城/springboot/src/database/create_tables.sql;
mysql> source E:/IdeaProjects/web_project/个性化推荐商城/springboot/src/database/insert_sample_data.sql;
```

**方法3：使用Navicat/DBeaver等图形工具**

1. 打开SQL文件 `create_tables.sql`
2. 点击"运行"执行

## 🔄 重新导入数据

如果需要重新导入，请按以下步骤：

### 方法1：删除并重建数据库
```sql
DROP DATABASE IF EXISTS product_system;
```
然后重新执行步骤2和步骤3

### 方法2：只删除数据（保留表结构）
```sql
USE product_system;

SET FOREIGN_KEY_CHECKS = 0;
DELETE FROM user_behavior;
DELETE FROM favorite;
DELETE FROM review;
DELETE FROM cart;
DELETE FROM `order`;
DELETE FROM product;
DELETE FROM category;
DELETE FROM address;
DELETE FROM user;
SET FOREIGN_KEY_CHECKS = 1;
```
然后重新执行步骤3

## ⚠️ 常见问题

### Q1: 密码加密的Hash值是什么？
**A:** 所有测试账号的密码都是 `123456`，Hash值为：
```
$2a$10$N.ZOn9G6/YLFixAOpJahl.CIeT5J7uMZV9FBgLfkzc/YmCGHmXB.y
```
这是BCrypt加密后的值，在Spring Boot中会自动验证。

### Q2: 图片路径问题？
**A:** 部分商品使用了占位图片路径 `/files/apple.jpg`，实际使用时需要：
1. 上传真实商品图片到 `springboot/files/img/` 目录
2. 或者通过后台管理系统上传图片
3. 前端会自动添加 `/api` 前缀

### Q3: 如何修改商品数据？
**A:** 直接编辑 `insert_sample_data.sql` 文件中的INSERT语句，然后重新导入。

### Q4: 推荐算法需要什么数据？
**A:** 已包含：
- ✅ 用户行为表 (`user_behavior`)
- ✅ 浏览记录
- ✅ 购买记录
- ✅ 收藏记录
- ✅ 时间序列数据

## 📊 数据库配置

### application.properties 配置示例：
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/product_system?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
spring.datasource.username=root
spring.datasource.password=your_password
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA配置
spring.jpa.hibernate.ddl-auto=none
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.format_sql=true
```
