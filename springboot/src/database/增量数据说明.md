## 🔍 验证数据

### 验证新分类

```sql
SELECT * FROM `category` 
WHERE name IN ('数码电器', '服装鞋包', '图书文娱', '家居生活', '运动户外', '美妆个护', '母婴玩具', '食品饮料');
```

### 验证新商品

```sql
SELECT p.*, c.name as category_name, u.name as shop_name
FROM `product` p
JOIN `category` c ON p.category_id = c.id
JOIN `user` u ON p.farmer_id = u.id
WHERE p.name IN ('Apple iPhone 15 Pro', 'Nike Air Max 270', 'SK-II神仙水', '《三体》全集')
ORDER BY p.price DESC;
```

### 验证折扣商品

```sql
SELECT name, price, discount_price, 
       ROUND((price - discount_price) / price * 100, 2) as discount_percent
FROM `product`
WHERE is_discount = 1 AND discount_price IS NOT NULL
ORDER BY discount_percent DESC;
```

## ⚠️ 注意事项

1. **不会删除原有数据**：本脚本仅追加数据
2. **可重复执行**：重复执行会插入重复数据（建议只执行一次）
3. **外键关联**：自动处理ID关联，无需手动修改
4. **执行时间**：约10-15秒
