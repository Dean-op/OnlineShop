# 个性化推荐商城 - 数据导入说明

## 📋 文件说明

本目录包含两个SQL脚本文件：

1. **`create_tables.sql`** - 数据库表结构创建脚本
2. **`insert_sample_data.sql`** - 示例数据插入脚本（新增）

## 🚀 使用步骤

### 步骤1：创建数据库和表结构

```bash
mysql -u root -p < create_tables.sql
```

或在MySQL客户端中执行：
```sql
source /path/to/create_tables.sql;
```

### 步骤2：插入示例数据

```bash
mysql -u root -p < insert_sample_data.sql
```

或在MySQL客户端中执行：
```sql
source /path/to/insert_sample_data.sql;
```

## 🔄 清空数据

如果需要重新导入数据，脚本会自动清空现有数据：

```sql
SET FOREIGN_KEY_CHECKS = 0;
TRUNCATE TABLE `user_behavior`;
-- ... 清空所有表
SET FOREIGN_KEY_CHECKS = 1;
```

⚠️ **警告**: 执行此操作会清空所有数据，请谨慎使用！
